\doxysubsection{Detailed Description}
It defines the command interpreter interface. 

Commands are defined by a Command\+Code, command regulates the interaction between the player and the game, and translates the player intention into a Command\+Code for game\+\_\+action.

This module also makes sure that till the user doesn\textquotesingle{}t enter a command, the game does not keep running.
