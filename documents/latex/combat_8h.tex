\doxysubsection{Detailed Description}
The combat module takes care of the game state COMBAT, checks stats of all entities involved and then creates all the logic of the combat. 

\begin{DoxyAuthor}{Author}
Maksym Polyak \&\& Daniel Gómez 
\end{DoxyAuthor}
Every time a combat starts, the combat struct is created and takes all the information from the space and the player.

Combat is based on turns, player turn and enemies turn, player can choose to run away or attack in their turn.
