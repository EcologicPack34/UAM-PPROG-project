Detailed Description

Defines the internal functionality of the links.

links are defined by an id, two spaces, a bool that regulates if they are locked or not and the id of an object that can unlock them. This makes the game able to create labyrints, teleports and more because two spaces don't need to be near in order for the player to move between them.
